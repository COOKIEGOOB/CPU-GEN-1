# Hybrid bond interface

The base die and the cache dielet are bonded **face to face** at 9 um pitch --
the same class of interconnect as AMD's SoIC-X. There are no microbumps and no
TSVs in the signal path; a bond is a direct copper-to-copper connection of
about 2.4 fF, which is why a 148-bit payload can cross in one cycle.

## Field

| | |
|---|---|
| channels | 8 |
| signal lanes per channel | 164 (144 payload + 4 command + 16 CRC) |
| spare lanes per channel | 8 |
| physical lanes per channel | 172 |
| total signal pads | 1376 |
| power/ground pads | 384 |
| control pads | 24 (forwarded clock, reset, train, DFT, fuse, power) |
| total pads per slice | 1784 |
| pitch | 9 um |
| field size | 3154 x 50 um |

The maps for both dies are generated by `pd/package/gen_bump_map.py` and
checked against each other by `pd/package/check_bond_alignment.py`, which fails
if a lane has no partner, if the mirror is wrong, if two pads overlap, or if a
signal pad has no return path within 27 um. The dielet map is the **mirror** of
the base map -- the classic 3D bring-up bug is getting that mirror backwards,
and it is worth a checker.

## Link layer

Per channel: 8 credits, CRC-16/CCITT over the 148-bit command+payload, replay
on error.

| event | action |
|---|---|
| CRC error | beat replayed from the credit buffer, counter incremented |
| 3 consecutive CRC errors | channel retrains (per-lane deskew) |
| more than 7 retrains | channel marked FAIL, ways retired via `way_mask` |
| dead lane found in training | remapped onto a spare through `lane_map` |
| more than 8 dead lanes | `lane_unrepairable`, the channel is retired |

Training walks a per-lane LFSR pattern, measures each lane, builds the
logical-to-physical `lane_map`, and repeats until every channel reports
`link_up`. The repair solver is proven in the Python model: up to 8 dead lanes
per channel are always repairable, 9 never are.

## Why a whole dead lane is survivable even mid-transfer

Each of the four 128-bit words of a line carries its own SECDED code. A stuck
lane corrupts at most one bit in each word, so all four words correct
independently. `tb/tb_vc3d_ecc.sv` injects exactly that pattern and checks the
line comes back clean; `tb/tb_vc3d_stack_bond.sv` does it through the modelled
bond with live traffic.

## Timing

Source-synchronous: the base die forwards a divided clock to the dielet, which
has no PLL of its own. The static budget is 180 ps each way (pad driver, 900 um
on-die run, receiver); per-lane deskew handles the rest. Constraints are in
`pd/sdc/vc3d_base.sdc` and `pd/sdc/vc3d_cache.sdc`.
